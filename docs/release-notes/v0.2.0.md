# Lunlet 0.2.0, unsigned preview

The second Lunlet preview: a redesigned panel under a small night sky, phone replies for Claude Code, a desktop pet, and more ways to keep an eye on your allowance.

## Before you open it

This preview is signed ad hoc and not notarized, because no Apple Developer Program membership stands behind it yet. On a new installation macOS therefore asks you to allow it once:

- macOS 15 and later: open Lunlet, choose Done in the dialog, then open System Settings › Privacy & Security, scroll to the Security section, choose Open Anyway next to Lunlet and confirm.
- macOS 14: right-click Lunlet.app, choose Open, then Open again.

Updating from 0.1.0 needs none of this: Lunlet shows a notice in the panel's footer, or choose Settings › About › Check for Updates…, and it restarts with your settings, skins and bot connection as they were. This is the first update Lunlet delivers to itself; if it does not arrive or does not finish, download the disk image below and replace Lunlet in Applications.

## Requirements

- macOS 14 or later on Apple silicon; this build is arm64 only.
- Codex (CLI or app) and/or Claude Code signed in on this Mac.

## New in this version

- **A redesigned panel.** Dark frosted glass under a night sky, with the Sun for all agents and one planet per agent whose lit side shows how much of its allowance is left. Choose a body to open that agent's page; the Overview keeps every agent's figures and the daily usage chart. Each agent's page shows three sessions at a time, Settings are grouped under tabs, and the allowance chart that opens from the figures states its forecast in words.
- **Phone replies for Claude Code.** While Claude Code is a selected agent, Lunlet adds one Stop entry to Claude Code's user settings and removes exactly that entry when you turn Claude Code off. A Claude Code turn that ends while the Mac is locked takes one reply from your Feishu or Lark, Slack or Telegram chat, which continues the same conversation; unlocking lets the turn go at once.
- **A desktop pet.** A small dog that sits on every Space, shows what your agents are doing and opens the panel as its speech bubble. A pack in Codex's pet format can take its place.
- **More about your allowance.** Codex's five-hour window beside its weekly one, and for a plan without a weekly window, the longer window it reports instead. The menu-bar entry can show the allowance closest to running out. A macOS notification can tell you when an allowance runs low or resets; it is off until you turn it on in Settings › Usage.
- **Needs you.** A cue at the notch, or from the pet, when a Claude Code session starts waiting for you, with an optional sound.
- **Steadier underneath.** Lower memory while reading long session records, and phone replies that survive a dropped connection.

## Changed

- The panel is dark in both the light and the dark appearance.
- Claude Code's page shows its weekly limit only: Claude Code stopped reporting a five-hour window to the status line Lunlet reads.

## Not in this version

- Answering an agent's question from your phone, and Needs you for Codex sessions.
- Claude Code's limit resets, per-model shares and usage credits: Claude Code reports only the weekly limit to Lunlet.
- Feishu cards have not yet been reviewed in the phone app.
- Intel Macs, Linux, Cursor and other agents.

## Privacy

Lunlet runs only on your Mac and has no servers, analytics or telemetry. Bot tokens stay in a file only your user account can read, sealed for this Mac and account; nothing is sent anywhere but the messaging provider you chose. Besides the status line it already added for limits, Lunlet now adds one Stop entry to Claude Code's user settings while Claude Code is selected, and removes both when you turn Claude Code off. The README's Privacy section lists exactly what a notice contains.
