# Lunlet 0.1.0, unsigned preview

The first downloadable Lunlet: a quiet companion at the notch for the Codex and Claude Code work already running on your Mac.

## Before you open it

This preview is signed ad hoc and not notarized, because no Apple Developer Program membership stands behind it yet. macOS therefore asks you to allow it once:

- macOS 15 and later: open Lunlet, choose Done in the dialog, then open System Settings › Privacy & Security, scroll to the Security section, choose Open Anyway next to Lunlet and confirm.
- macOS 14: right-click Lunlet.app, choose Open, then Open again.

Updates arrive inside Lunlet and need none of this.

## Requirements

- macOS 14 or later on Apple silicon; this build is arm64 only.
- Codex (CLI or app) and/or Claude Code signed in on this Mac.

## What it does

- Shows "lun" and "let" beside the notch, joined by one vine strand per agent that shows how much of its weekly allowance is left; hover to preview the panel, click to keep it open. Macs without a notch get the same panel from the menu bar.
- Lists active and past Codex and Claude Code sessions with each one's latest request, status and tokens, and tells you at the notch when a turn finishes.
- Shows the Codex weekly allowance and credits, Claude Code's five-hour and weekly limits, and today's and this week's tokens and cost per agent.
- While the Mac is locked and awake, sends each finished turn to the Feishu or Lark, Slack or Telegram bot and private chat you paired, with its outcome, your request and the agent's reply; one reply per notice continues that Codex session with its existing sandbox and approval settings.
- Vine and Lantern skins in any color, custom skins, light and dark appearance.

## Not in this version

- Replies to Claude Code sessions, and answering an agent's question from your phone.
- Feishu cards have not yet been reviewed in the phone app.
- Intel Macs, Linux, Cursor and other agents.
- An in-app update from this version is accepted when the next version ships; if one fails, download the new disk image instead.

## Privacy

Lunlet runs only on your Mac and has no servers, analytics or telemetry. Bot tokens stay in a file only your user account can read, sealed for this Mac and account; nothing is sent anywhere but the messaging provider you chose. The README's Privacy section lists exactly what a notice contains.

## Files

- `Lunlet-0.1.0-macos-arm64.dmg`: the download; open it and drag Lunlet to Applications.
- `Lunlet-0.1.0-macos-arm64.zip`: the archive Lunlet's updater installs; not meant for manual installation.
- `SHA256SUMS`, `manifest.json`, `LICENSE` and `NOTICE.md`: checksums, the build's provenance (source tag, revision, signing and notarization status) and the licenses.
