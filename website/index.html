Current source preview

Codex and Claude Code are available for local evaluation. macOS 14 is the deployment target; on-device validation currently covers macOS 27 on Apple silicon. A broader tested range will accompany a release.

Read-only observation includes locally owned Codex and Claude Code records. Some client workflows still need on-device validation. Locked-Mac delivery and one reply per notice are verified on Feishu, Telegram and Slack.

Release availability

Source-only preview: a public macOS download is not available yet. The source uses 0BSD; artwork and privacy claims still need publication review, and a macOS download needs signing and installation checks.
